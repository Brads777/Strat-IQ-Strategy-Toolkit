StratOS: continue from Part 1

How to run the updated toolkit so it finds the external analysis you already did and carries on into the internal analysis, instead of starting again.

Updated: Parts 2 and 3 now install together. Use the Parts 2 + 3 guide instead of this page.
The short version. StratOS saves everything to one file, the strategy-ledger. Put that file in your Project, install the new skills, and say "continue my analysis". StratOS reads the file, sees what is finished, and starts at the next step.

What changed

The toolkit now has two parts.

PartWhat it coversSteps
Part 1: the industry
(external analysis)		 What the industry rewards Industry Overview, Competitive Analysis, PESTEL, Five Forces, Trending Influence Factors, KSFs, Strategic Mapping
Part 2: the company
(internal analysis, new)		 What the company can do about it Value Chain, Resources and Capabilities, VRIO, SWOT

A new orchestrator, stratos-orchestrator-final, replaces the old one. When it opens, its first job is to check whether Part 1 has been done.

Before you start: find your ledger file

  1. Look for the file you saved during Part 1. Its name starts with strategy-ledger- and ends in .json, for example strategy-ledger-global-ev-2026.json. Check two places:
    • the Project knowledge panel of your StratOS Project in Claude Projects;
    • your computer's Downloads folder.
  2. If you cannot find it, get it from the Part 1 chat. Open the chat where you ran Part 1 and type: Give me the strategy ledger as a file I can download. Download the file it offers.
  3. If that chat is gone too, do nothing more here. StratOS will find no ledger and run the whole process, Part 1 then Part 2. Nothing breaks; it takes longer.

Set up the updated toolkit

  1. Download the Part 2 upload. Go to the latest StratOS release and, under Assets, download stratos-part2-skills.zip. Unzip it once. Inside are seven smaller zip files, one per skill. Do not unzip those. The fourteen skills you uploaded in Part 1 stay as they are.
  2. Upload the five new skills. Open Settings → Capabilities, find Skills, choose Upload skill, and upload each of these:
    • stratos-orchestrator-final.zip
    • stratos-value-chain.zip
    • stratos-resources-capabilities.zip
    • stratos-vrio.zip
    • stratos-swot.zip
  3. Replace the two skills that were updated. Upload stratos-case-exhibits.zip and stratos-strategic-mapping.zip again. If Claude says a skill with that name already exists, delete the old one in the Skills list first, then upload.
  4. Turn off the old orchestrator. In the Skills list, switch off (or delete) stratos-orchestrator. Leave stratos-orchestrator-final on.
    Do not skip this. The new orchestrator is written to take over and will remind you if the old one is still on, but only you can switch a skill off. With both on, "run StratOS" can still open the old one first, which does not know about Part 2.
  5. Check the list. You should see eighteen StratOS skills switched on: the thirteen you kept from before, plus the five new ones.

Run it so it picks up where you left off

  1. Put the ledger in your Project. Open your StratOS Project. If the strategy-ledger file is not already in Project knowledge, add it there. Keep only one ledger per industry; remove older copies so StratOS does not read the wrong one.
  2. Start a new chat inside the Project. A new chat, not the old Part 1 chat. Type: Run StratOS and continue my analysis from where I left off.
  3. Read what StratOS reports back. Before it runs anything, it tells you what it found, for example: Part 1 is complete for the global EV industry, base company BYD, as of 2026-09-30. Continuing with Part 2 at Value Chain. If that is not what you expected, stop and check the troubleshooting table below.
  4. Confirm the base company. StratOS asks whether to keep the same company. Part 2 studies that one company from the inside. If you want a different company, say so now; it redoes the company-specific steps of Part 1 first, then continues.
  5. Give it the inside information when it asks. Part 2 needs facts about the company itself: what it owns, what it does well and badly, where its costs fall, what its customers choose on. For a case, paste your persona interview notes. For a public company, StratOS uses its annual report. Anything it cannot find is marked [ask in interview]; it does not make facts up.
  6. Work through the four steps. Value Chain, Resources and Capabilities, VRIO, SWOT. After each one StratOS shows the result and asks continue, revise or stop.
  7. Save the ledger every time it is offered. At each checkpoint StratOS offers the updated ledger as a download. Download it and replace the copy in Project knowledge. This is what lets the next chat pick up from the right place.
  8. Collect the deliverables. At the end you get the full report (Word), the 15-slide executive deck (PowerPoint), and the final ledger.

What StratOS does with what it finds

It findsIt does
Part 1 completeSkips setup and Part 1. Starts Part 2 at Value Chain.
Part 1 partly doneTells you the last finished step, finishes Part 1 from the next step, then runs Part 2.
Part 2 partly doneResumes Part 2 at the next step.
Both parts completeOffers the report and deck, a change of base company, or a refresh of out-of-date items.
No ledger, or a ledger for a different industryRuns the entire process: setup, Part 1, then Part 2.
Out-of-date evidence in Part 1Lists the affected steps and re-runs those before Part 2.

Building case-memo exhibits instead

  1. Start the same way. Ledger in Project knowledge, new chat, then type: Run StratOS. Build my case-memo exhibits and continue from where I left off.
  2. Let it reuse Exhibits C to G. If your ledger already holds the industry analysis, StratOS keeps those exhibits and builds H. Resources and capabilities, I. VRIO, J. Value Chain and K. SWOT from your interview notes, then L to O.
  3. Choose your own alternatives. Exhibit K ends with a table of strategic options. They are candidates. You decide which become the alternatives in your Decision Matrix, and StratOS asks you to confirm them first.
  4. Write what is yours. The memo, Exhibits A and B, and every Impact Summary are left blank for you.

If it does not pick up where you left off

What you seeLikely causeFix
It asks you to choose an industry from scratch No ledger in Project knowledge, or the chat is outside the Project Add the ledger to Project knowledge and start a new chat inside the Project
It shows the old eight-step intro with no Part 2 The old orchestrator opened Switch off stratos-orchestrator in Settings → Capabilities and start a new chat
It says Part 1 is only partly done The ledger you uploaded is an early copy Find the most recent ledger download, replace the copy in Project knowledge, start a new chat
It names the wrong industry or company More than one ledger in Project knowledge Remove the ones you do not want, start a new chat
A step says it "ran without its skill" That skill is not uploaded or is switched off Upload or switch it on, then say "redo that step"
Many items marked [ask in interview] Your notes do not cover the inside of the company Interview the personas again with those questions, paste the answers, say "update Part 2"

Using Claude Code instead of Claude.ai

  1. Check the ledger is in place. It lives at .strategy/ledgers/<scope>.json in the folder you run Claude Code from. There is nothing to upload.
  2. Run it. Type the same request: Run StratOS and continue my analysis from where I left off. StratOS reads the ledger from that folder and saves back to it after every step.
