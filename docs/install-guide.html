1. Students: set up in Claude.ai (about 5 minutes)

Nothing to install on your computer. You upload the skills once, then use them in any chat.

Check first: if your instructor says the Strat-IQ skills are already enabled for your class, skip to step 4.
  1. Turn on code execution. Open Claude.ai → Settings → Capabilities and switch on Code execution and file creation. Skills need it.
  2. Download the skills. Go to the latest release and download stratiq-all-skills.zip. Unzip it — inside are fourteen smaller zips, one per skill. Do not unzip those fourteen.
  3. Upload the fourteen skills. In Settings → Capabilities, find Skills, choose Upload skill, and upload each of the fourteen zips. Make sure all fourteen show as enabled.
  4. Create a Project. In the left sidebar choose Projects → New project, and name it, for example, Strat-IQ — EV industry.
  5. Add the class data. Download industries.json (use the download button) and add it to the Project's knowledge.
  6. Start. Open a new chat inside the Project and type: 
    Run Strat-IQ External Analysis
    The intro screen appears and asks how you want to work.

2. Instructors and admins: enable it for a whole class

  1. Ask your Claude admin (for NEU, the team that manages the Canvas-linked Claude.ai) whether members can upload custom skills, and whether web search is enabled — Competitive Analysis needs it for financials and news.
  2. Provision org-wide if you can. An admin can add the fourteen skills for everyone, so students skip steps 1–3 above. Use the per-skill zips from the latest release.
  3. Set the class list. Edit project-data/industries.json: keep your course industry at "locked": true so students analyse exactly the competitors you choose.
  4. Dry-run it yourself in guided mode on the class industry before assigning it, and keep any worked answers out of the files you share.

3. Claude Code (terminal users)

  1. Clone the repo and copy the skills: 
    git clone https://github.com/Brads777/Strat-IQ-Strategy-Toolkit.git
cp -r Strat-IQ-Strategy-Toolkit/skills/stratiq-* ~/.claude/skills/
  2. In the folder where you want to work, copy the project data: 
    mkdir -p project-data
cp /path/to/Strat-IQ-Strategy-Toolkit/project-data/industries.json project-data/
  3. Start claude and type Run Strat-IQ External Analysis. The ledger is saved to .strategy/ledgers/.
  4. The KSF scorer needs Python 3.10 or newer: 
    python ~/.claude/skills/stratiq-ksf/scripts/score_ksf.py ksf-scores.csv

4. Optional: live financial data with OpenBB

Without this, Competitive Analysis uses SEC EDGAR and web research. With it, financials come from one consistent data layer.

  1. Install and start the server (Python 3.9–3.12): 
    pip install openbb-mcp-server
openbb-mcp --transport streamable-http --default-categories admin
  2. Optionally add provider keys to ~/.openbb_platform/user_settings.json under credentials (for example an FMP key). Free providers work without keys.
  3. Connect the server to Claude as an MCP server. Details and tool list: openbb-mcp.md · OpenBB on GitHub (AGPLv3).

5. Running an analysis

The intro screen offers four choices

ChoiceWhat happens
A. Walk me through itAll eight steps in order. After each step you see the results and choose continue, revise, or stop. At the end you get a detailed, cited research report (Word) and a 15-slide executive PowerPoint. The report covers the industry overview, attractiveness, trends, competitive landscape, KSF scorecard, both strategic maps, recommended moves, a watch list, and a confidence check.
B. Ask a specific questionOnly the steps your question needs are run. The answer starts by saying which steps ran.
C. Build my case-memo exhibitsFor the Case Analysis Memo: enter the case facts you gathered (company, industry, competitors, and your persona interview notes) plus your Exhibits A and B. Strat-IQ builds Exhibits C–G and L–O in the template order as a Word file. You write the memo, Exhibits A–B, and every Impact Summary.
ResumeAttach your saved ledger file and continue where you stopped.

The eight steps

  1. Set up — industry, competitors, base company, perspective, quick or full depth.
  2. Industry Overview — what the industry is, its size and growth, segments, economics, history, leaders, and life-cycle stage.
  3. Competitive Analysis — financials, annual-report risk factors, news and hiring signals, moats.
  4. PESTEL Analysis — macro factors, each tied to a line of the P&L.
  5. Porter's Five Forces — how hard it is to make money here, and who captures the profit.
  6. Trending Influence Factors — the 3–5 changes that will reshape the industry.
  7. KSFs — what it takes to win, and a scorecard for every competitor.
  8. Strategic Mapping — where competitors cluster, and where the empty space is.

Save your work at every checkpoint

Strat-IQ keeps everything in one ledger file (strategy-ledger-….json). At each checkpoint, download it and replace the copy in your Project's knowledge. A full eight-step run is long — if a chat gets too long or you hit a usage limit, open a new chat in the same Project and type resume.

Try these

  • Run Strat-IQ External Analysis on the EV industry with BYD as the base company.
  • What are the key success factors for EVs, and who is strongest?
  • Now make Stellantis the base company. — the industry analysis is reused; only the company view reruns.

6. Troubleshooting

ProblemFix
No Skills section or no upload buttonTurn on Code execution and file creation first. If it still is not there, your organisation controls skills — ask your instructor or admin.
"Run Strat-IQ External Analysis" does nothing specialCheck all fourteen skills are uploaded and enabled, and that you are chatting inside the Project.
It asks for the industry every timeAdd industries.json to the Project knowledge (step 5).
Financial figures marked [E] or [unverified]That is deliberate: private companies publish no audited financials. Strat-IQ labels estimates instead of inventing numbers.
Maps say scoring: public-screenNormal in class. The proprietary Strat-IQ scoring service is not connected; a transparent public method is used instead.
